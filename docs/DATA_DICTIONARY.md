# Data Dictionary

This directory contains detailed documentation for each sheet in the "Keyword Planner Automation" spreadsheet.

## Sheet Documentation

1.  [**Intent Types**](./sheets/01_INTENT_TYPES.md) - Configuration of keyword categories and negative keywords.
2.  [**Raw Data**](./sheets/02_RAW_DATA.md) - Entry point for importing raw keyword data.
3.  [**Clean Data**](./sheets/03_CLEAN_DATA.md) - Staging area for processed, deduplicated, and filtered keywords.
4.  [**Clusters**](./sheets/04_CLUSTERS.md) - Results from Arsenkin Clustering API.
5.  [**Ads Data**](./sheets/05_ADS_DATA.md) - Main feed for Google Ads Editor (Standard).
6.  [**Settings**](./sheets/06_SETTINGS.md) - Global project configuration and API keys.
7.  [**Ads Variants**](./sheets/07_ADS_VARIANTS.md) - Structure for "Ads Phrase" and "Ads Adaptive" sheets.
