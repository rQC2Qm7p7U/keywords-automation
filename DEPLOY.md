# Инструкция по деплою (Deploy) и обновлению кода

Этот файл содержит инструкции о том, как правильно сохранять изменения в Git и загружать их в Google Apps Script (GAS).

## Быстрые команды (Рекомендуется)

В проекте настроены специальные команды для автоматизации. Откройте терминал в папке проекта и используйте одну из следующих команд:

### 1. Полная синхронизация (Save & Deploy)
Используйте эту команду, когда вы закончили работу над задачей и хотите сохранить изменения в Git и сразу загрузить их в Google Spreadsheets.

```bash
npm run sync
```
**Что она делает:**
1.  `npm run deploy` — Собирает проект (build) и загружает его в GAS (`clasp push`).
2.  `git add .` — Добавляет все измененные файлы.
3.  `git commit -m 'chore: sync'` — Создает коммит с сообщением "chore: sync".
4.  `git push` — Отправляет изменения в удаленный репозиторий GitHub.

---

### 2. Только загрузка в Google Sheets (Deploy Only)
Используйте эту команду, если вы хотите просто проверить изменения в таблице, не создавая коммит в Git.

```bash
npm run push
```
**Что она делает:**
1.  `clasp push` — Загружает файлы из папки `dist/` в Google Apps Script.

---

## Ручной режим (для понимания)

Если автоматические команды не работают или вам нужно больше контроля (например, свое сообщение коммита), выполняйте шаги последовательно:

### Шаг 1: Сборка и Загрузка (Deploy)
```bash
npm run build        # Собирает TypeScript в JavaScript (папка dist/)
npx clasp push       # Загружает файлы из dist/ в облако
```

### Шаг 2: Сохранение в Git (Commit & Push)
```bash
git add .                           # Добавить все файлы
git commit -m "Ваше сообщение"      # Создать коммит (напишите, что изменили)
git push                            # Отправить на GitHub
```

## Важные советы

1.  **Никогда не меняйте код прямо в редакторе Google Apps Script в браузере.**
    Ваши локальные изменения перезапишут код в облаке при следующем `clasp push`. Всегда пишите код локально в VS Code.

2.  **Если возник конфликт (Manifest file has been updated):**
    Это значит, кто-то изменил файл в онлайне.
    Выполните `npx clasp pull`, чтобы скачать изменения, а затем снова попытайтесь сделать push. Но лучше следуйте правилу №1.

3.  **Игнорируемые файлы:**
    Файл `DEPLOY_INSTRUCTION_RU.md` добавлен в `.gitignore` и не попадет в репозиторий, он останется только у вас локально.
