# 📘 Инструкция пользователя: АВТОМАТИКА для Keyword Planner

Этот инструмент превращает Google Таблицу в мощное рабочее место для сбора, фильтрации и кластеризации ключевых слов.

---

## 🚀 Быстрый старт

1.  Откройте таблицу.
2.  Дождитесь появления меню **"АВТОМАТИКА"** (справа от "Справка").
3.  Выберите **"1. Создать структуру таблицы"** для инициализации.

---

## 🛠 Рабочий процесс

Инструмент организован по этапам работы с семантикой: от сбора данных до создания объявлений.

### Этап 1: Подготовка данных

#### 1. Создать структуру таблицы
`Function: handleCreateStructure`
-   **Действие:** Полный сброс и создание всех необходимых листов (`Raw Data`, `Clean Data`, `Intent Types`, `Settings`, `Ads Data`).
-   **Важно:** Используйте только в начале нового проекта. Все существующие данные на рабочих листах будут удалены.

#### 2. Удалить дубликаты (Raw/Clean)
`Function: handleRemoveDuplicates`
-   **Действие:** Удаляет полные дубликаты ключевых слов на листах `Raw Data` и `Clean Data`.
-   **Результат:** Оставляет только первое уникальное вхождение каждого слова.

### Этап 2: Очистка и Фильтрация

#### 3. Собрать минуса (Intent Types)
`Function: handleCollectNegatives`
-   **Действие:** Сканирует колонку "Negative" на всех листах (`Raw`, `Clean`, `Clusters`) и собирает уникальные минус-слова на лист `Intent Types`.
-   **Особенности:**
    -   Разбивает списки (через запятую/точку с запятой) на отдельные слова.
    -   Сортирует по алфавиту.
    -   **Подсветка:** Зеленым отмечаются успешно перенесенные слова, желтым — дубликаты.

#### 4. Перенос Raw -> Clean
`Function: handleTransferRawToClean`
-   **Действие:** Умный перенос данных из "грязного" списка (`Raw Data`) в чистовой (`Clean Data`).
-   **Правила фильтрации:**
    -   Игнорирует пустые ключевые слова.
    -   Игнорирует дубликаты (проверяет наличие в `Clean Data`).
    -   Игнорирует слова с низким спросом (Avg. searches <= 0).
    -   **Минус-слова:** Не переносит фразы, содержащие слова из списка `Intent Types`.
-   **Форматирование:** Автоматически исправляет форматы чисел и округляет значения.

#### 5. Отчистить ключи от минусов (Clean)
`Function: handleCleanKeysFromNegatives`
-   **Действие:** Проверяет уже перенесенные ключи в `Clean Data` на наличие минус-слов.
-   **Когда применять:** Если вы добавили новые минус-слова в `Intent Types` после переноса данных.
-   **Важно:** Использует поиск целого слова (удалит "car", но оставит "carpet").

### Этап 3: Кластеризация (Arsenkin)

Для работы требуется API токен сервиса [Arsenkin.ru](https://arsenkin.ru/).

#### Настройка
1.  В меню выберите **"Настройки" -> "Установить API токен"**.
2.  На листе `Settings` выберите регион поиска.

#### 6. Кластеризация (Ars API)
`Function: handleRunClustering`
-   **Действие:** Отправляет ключевые слова из `Clean Data` на группировку.
-   **Результат:** Вы запускаете задачу на сервере. ID задачи сохраняется в системе.

#### 7. Проверить статус последней задачи
`Function: handleCheckLastTask`
-   **Действие:** Проверяет готовность кластеризации.
-   **Результат:**
    -   Если готово: Скачивает результаты и заполняет лист `Clusters`.
    -   Если нет: Показывает текущий статус и прогресс.

### Этап 4: Объявления (Google Ads)

#### 8. Форматировать объявления (CamelCase)
`Function: handleFormatAdsData`
-   **Действие:** Форматирует заголовки и описания на листе `Ads Data`.
-   **Правила (Ads Case):**
    -   **Headlines:** Title Case (Каждое Слово С Большой).
    -   **Descriptions:** Только проверка начал предложений (Заглавная буква) и удаление лишних символов. Регистр остальных слов сохраняется.
    -   Предлоги (in, on, for, etc.) остаются строчными.
    -   Аббревиатуры (из списка `Abbreviations` на листе `Intent Types`) — ЗАГЛАВНЫМИ.
    -   Удаляет запрещенные символы (`@`, `<`, `>`).
    -   Удаляет `!` из заголовков.
    -   Исправляет пробелы и пунктуацию (двойные запятые, пропущенный пробел после знаков).
    -   **UTM метки:** Автоматически генерирует (или обновляет) ссылку `Final URL` с UTM-метками на основе настроек листа `Settings`. Значения подставляются «как есть» — плейсхолдеры (`{keyword}`, `{campaignid}`, `{creative}`, `{device}`) **не** транслитерируются и передаются в ссылку без изменений.
    -   **Автоматизация:** Эти же правила форматирования применяются **автоматически** при любом изменении или вставке данных в колонки заголовков/описаний на листе `Ads Data`.

#### 9. Перенос Clusters -> Ads Data
`Function: handleTransferClustersToAdsData`
-   **Действие:** Переносит сгруппированные данные из листа `Clusters` на лист `Ads Data`.
-   **Маппинг:**
    -   `Group name` (из Clusters) -> `Ad Group` (в Ads Data).
    -   `Keyword` (из Clusters) -> `Keyword`.
    -   `Headline 1` автоматически формируется из ключа.
    -   **UTM метки:** Ссылка `Final URL` формируется автоматически с учетом настроек UTM (см. раздел Настройки).
-   **Очистка:** Перед переносом лист `Ads Data` полностью очищается.

## ⚙️ Настройки (Лист Settings)

-   **Region Search / Region:** Выбор региона для кластеризации.
-   **Campaign Name:** Название кампании для экспорта в Ads.
-   **Target URL:** Целевая ссылка для объявлений.
-   **UTM Settings:** Настройка меток (Source, Medium, Campaign, Content, Term, Device).
    -   Значения передаются в ссылку «как есть». Плейсхолдеры Google Ads (`{keyword}`, `{campaignid}`, `{creative}`, `{device}`) сохраняются без изменений — Google Ads подставит реальные значения при показе.
    -   Параметры очищаются от спецсимволов (`#`, `=`, `&`) и переводятся в нижний регистр.
-   **Limits:** Настройка ограничений длины заголовков (по умолчанию 30) и описаний (по умолчанию 90).

## ❓ FAQ / Частые вопросы

**Q: Меню "АВТОМАТИКА" не появилось?**
A: Обновите страницу (F5). При первом запуске Google может запросить разрешение.

**Q: Список регионов пуст?**
A: Введите начало названия города в ячейку `Region Search` (B3) на листе Settings.

**Q: Почему не переносятся слова из Raw в Clean?**
A: Проверьте:
   1. Не является ли слово дубликатом?
   2. Не содержит ли оно минус-слово?
   3. Есть ли у него частотность (Avg. searches > 0)?
