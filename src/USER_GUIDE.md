# Инструкция пользователя: АВТОМАТИКА для Keyword Planner

## Введение
Этот инструмент помогает быстро подготовить рабочее пространство для обработки ключевых слов.

## Основные функции

### Меню "АВТОМАТИКА"
После перезагрузки или открытия таблицы, в верхнем меню появится новый пункт **"АВТОМАТИКА"**.

### 1. Создать структуру таблицы
Эта функция полностью пересобирает таблицу для начала работы.

**⚠️ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ:**
Эта функция **УДАЛИТ ВСЕ** существующие листы и данные в текущей таблице. Используйте её только когда вы хотите начать с чистого листа или предварительно сохранили свои данные.

**Как использовать:**
1. Нажмите на меню **АВТОМАТИКА**.
2. Выберите пункт **1. Создать структуру таблицы**.
3. Появится всплывающее окно с предупреждением.
4. Нажмите **Да**, чтобы подтвердить удаление старых данных и создание новой структуры.
5. Нажмите **Отмена**, если вы передумали.

**Результат:**
Произойдет очистка таблицы и создание двух новых листов:

1. **"Intent Types"** (первая вкладка):
   - Transactional
   - Branded
   - Commercial
   - Local
   - Abbreviations
   - Negative

2. **"Raw Data"** (вторая вкладка) — лист для сырых данных:
   - Keyword
   - Currency
   - Avg. monthly searches
   - Изменение за квартал
   - Изменение за год
   - Competition
   - Competition index
   - Bid Low
   - Bid High
   - Negative

3. **"Clean Data"** (третья вкладка) — лист для чистых данных:
   - Keyword
   - Avg. monthly searches
   - Competition index
   - Bid Low
   - Bid High
   - Negative

> **Примечание:** Заголовки (первая строка) всех созданных листов автоматически блокируются от изменений. Редактировать их может только владелец таблицы.

### 3. Собрать минуса (Intent Types)
Собирает минус-слова из листов **Raw Data** и **Clean Data** (колонка Negative), удаляет дубликаты, сортирует и сохраняет в **Intent Types**.
Также подсвечивает:
- Совпадения в Intent Types (желтым).
- Обработанные минус-слова в Raw/Clean Data (зеленым).

### 4. Перенос Raw -> Clean
Копирует данные из **Raw Data** в **Clean Data** для следующих колонок:
- Keyword
- Avg. monthly searches
- Competition index
- Bid Low
- Bid High

**Особенности:**
- Автоматически форматирует числа (меняет запятую на точку).
- Применяет форматирование:
  - Avg. monthly searches, Competition index: Целое число (`0`).
  - Bid Low, Bid High: Дробное число (`# ##0.00`).

### 5. Отчистить ключи от минусов (Clean)
Удаляет строки из листа **Clean Data**, если ключевое слово (Keyword) содержит минус-слово из **Intent Types** (колонка Negative).
**Важно:** Используется поиск *целого слова* (whole word matching). 
*Пример:* Минус-слово "car" удалит "rent a car", но оставит "carpet".

### 6. Кластеризация (Arsenkin API)
Инструмент интегрирован с сервисом Arsenkin Tools для автоматической кластеризации запросов.

**Настройка:**
1. Перейдите на лист **"Ars API Set"**.
2. **API Token**: Нажмите в меню **"АВТОМАТИКА" -> "🔐 Арсенкин: Установить токен"**. Введите ваш токен. Статус обновится на "Set".
3. **Регион (Умный поиск)**:
   - В ячейке **"Region Search"** начните вводить название города (рус/англ), например `Моск` или `Mosc`.
   - В ячейке **"Region"** (ниже) выберите нужный город из выпадающего списка. Список автоматически фильтруется по вашему запросу.
4. Настройте остальные параметры (Top, Glubina и т.д.) на листе настроек.

**Запуск:**
1. Нажмите **"АВТОМАТИКА" -> "6. Кластеризация (Ars API)"**.
2. Скрипт соберет ключи из листа **Clean Data**, создаст задачу в Arsenkin и будет ждать результата.
3. По завершении результаты (Группа, URL) будут записаны на лист **"Clusters"**.

**Примечание:** Если ключей много (>20 000), скрипт запросит дополнительное подтверждение.

### 7. Проверка статуса задачи
Если во время кластеризации произошел тайм-аут (скрипт работал > 5 минут), вы можете проверить статус задачи позже вручную.

1. Нажмите **"АВТОМАТИКА" -> "7. Проверить статус последней задачи"**.
2. Если задача готова, результаты загрузятся в лист **Clusters**.

### 🔐 Установка Токена (Arsenkin)
Для работы кластеризации требуется API токен.
1. Получите токен в личном кабинете Arsenkin Tools.
2. В Google Таблице нажмите меню **"АВТОМАТИКА" -> "🔐 Арсенкин: Установить токен"**.
3. Вставьте токен и нажмите OK.
*Токен сохраняется безопасно в свойствах скрипта и не виден в таблице.*

### Удаление дубликатов
Инструмент позволяет очистить листы "Raw Data" и "Clean Data" от повторяющихся ключевых слов.

1. Убедитесь, что данные загружены в "Raw Data" или "Clean Data".
2. Нажмите **"АВТОМАТИКА"** -> **"2. Удалить дубликаты (Raw/Clean)"**.
3. Скрипт проверит оба листа и удалит строки, где ключевое слово (Колонка A) повторяется.
4. Вы увидите всплывающее сообщение с количеством удаленных строк для каждого листа.

**Важно:**
- Дубликаты ищутся внутри каждого листа отдельно (Raw Data сам по себе, Clean Data сам по себе).
- Сравнение идет по полному совпадению текста.

## Что делать, если меню не появилось?
Попробуйте обновить страницу браузера. Если меню все еще не появляется, обратитесь к администратору или разработчику.
