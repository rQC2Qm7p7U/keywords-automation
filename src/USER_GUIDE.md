# 📘 Инструкция пользователя: АВТОМАТИКА для Keyword Planner

Этот инструмент превращает Google Таблицу в мощное рабочее место для сбора, фильтрации и кластеризации ключевых слов.

---

## 🚀 Быстрый старт

1. Откройте таблицу.
2. Дождитесь появления меню **"АВТОМАТИКА"** (справа от "Справка").
3. Нажмите **"АВТОМАТИКА" -> "1. Создать структуру таблицы"**.
4. Подтвердите действие. Скрипт создаст необходимые листы.

---

## 📋 Описание Функций Меню

### 1. Создать структуру таблицы
**Назначение:** Полный сброс и настройка рабочего пространства.
- **Внимание:** Эта функция **УДАЛЯЕТ ВСЕ** листы (кроме скрытых системных) и создает заново:
    - `Intent Types`: Для работы с минус-словами.
    - `Raw Data`: Для загрузки "грязных" данных из планировщика.
    - `Clean Data`: Для чистовых данных.
    - `Ars API Set`: Настройки для кластеризации.
- **Когда использовать:** При начале нового проекта.

### 2. Удалить дубликаты (Raw/Clean)
**Назначение:** Очистка списков от повторов.
- **Как работает:**
    - Ищет полные дубликаты ключевых слов (Колонка A) на листах `Raw Data` и `Clean Data`.
    - Оставляет только первое вхождение.
    - Удаляет лишние строки.

### 3. Собрать минуса (Intent Types)
**Назначение:** Агрегация минус-слов.
- **Как работает:**
    - Сканирует колонку "Negative" на листах `Raw Data` и `Clean Data`.
    - Копирует все уникальные слова в колонку "Negative" на листе `Intent Types`.
    - **Подсветка:**
        - **Желтый** (Intent Types): Слова, которые уже есть в списке.
        - **Зеленый** (Raw/Clean): Слова, которые успешно перенесены.

### 4. Перенос Raw -> Clean
**Назначение:** Подготовка данных к работе.
- **Действие:** Копирует данные из `Raw Data` в `Clean Data`.
- **Авто-форматирование:**
    - Исправляет числа: заменяет запятые на точки (для корректной работы формул).
    - Округляет метрики (Avg. searches = целое, CPC = 2 знака).

### 5. Отчистить ключи от минусов (Clean)
**Назначение:** Фильтрация ключей.
- **Как работает:**
    - Проверяет каждый ключ в `Clean Data`.
    - Если ключ содержит любое слово из списка "Negative" (лист `Intent Types`), строка удаляется.
    - **Важно:** Используется поиск **целого слова** (например, минус "car" удалит "rent car", но оставит "carpet").

## 🧩 Кластеризация (Arsenkin API)

Инструмент умеет автоматически группировать запросы через сервис Arsenkin Tools.

### Шаг 1: Настройка Токена
*Делается один раз.*
1. Получите API токен в личном кабинете [arsenkin.ru](https://arsenkin.ru/).
2. В таблице: **"АВТОМАТИКА" -> "🔐 Арсенкин: Установить токен"**.
3. Введите токен. Он сохранится в защищенном хранилище скрипта.

### Шаг 2: Настройка Параметров (Лист "Ars API Set")
Перейдите на лист `Ars API Set` и настройте параметры:

1. **Search Engine**: Google или Yandex.
2. **Region (Умный Поиск)**:
   - **Region Search (Ячейка B3)**: Введите начало названия города (например, `Моск` или `Mosc`).
   - **Region (Ячейка B4)**: Выберите нужный регион из выпадающего списка. Список **автоматически фильтруется** по введенному вами тексту.
   - *Это позволяет работать с базой из 40,000+ городов без зависаний.*
3. **Group Type**: Hard (строгая) или Soft (мягкая).
4. **Group Count**: Минимальное кол-во совпадений (обычно 3).

### Шаг 3: Запуск (Меню п. 6)
1. Нажмите **"6. Кластеризация (Ars API)"**.
2. Скрипт отправит все ключи из листа `Clean Data` на сервер.
3. Если ключей много (>20 000), скрипт запросит дополнительное подтверждение.
4. Дождитесь уведомления о создании задачи.

### Шаг 4: Получение результатов
- Скрипт автоматически проверяет статус задачи каждую минуту.
- Когда задача готова, создается лист `Clusters` с результатами (Ключ, Группа, URL).
- **Если скрипт работал дольше 5 минут (тайм-аут Google):**
    - Нажмите **"7. Проверить статус последней задачи"**.
    - Если задача на сервере готова, результаты загрузятся.

## ❓ Частые вопросы

**Меню "АВТОМАТИКА" не появилось?**
- Обновите страницу (F5). В первый раз Google может потребовать разрешения на запуск скриптов.

**Выпадающий список регионов пустой?**
- Убедитесь, что вы ввели текст в ячейку **Region Search** (B3).
- Если список все равно пуст, попробуйте перезапустить **"1. Создать структуру таблицы"**.

**Как изменить заголовки колонок?**
- Заголовки защищены программно. Изменять их нельзя, так как это нарушит работу алгоритмов переноса данных.
